# AI Customer Support & Automation Platform

An AI-powered customer support platform built with React,
FastAPI, Python, SQLite, NLP, and Ollama.

## Core Features

- Customer chat
- Intent detection
- FAQ / knowledge base
- AI response generation
- Ticket creation
- Ticket priority detection
- Escalation
- Conversation history
- Admin dashboard
- Automation workflows

## Tech Stack

Frontend:
- React
- Vite

Backend:
- FastAPI
- Python
- SQLAlchemy

AI / NLP:
- Scikit-learn
- Ollama
- Llama 3.2

Database:
- SQLite
